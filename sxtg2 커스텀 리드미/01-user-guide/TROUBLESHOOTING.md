# 트러블슈팅(모음) - sxtg2 기준

기준일: 2026-10-05 (v1.1.0, 알려진 문제 일괄 수정 반영)

로그는 `{게임 설치 폴더}\MelonLoader\Latest.log`에 남습니다. 자세히 보고 싶으면 `UserData\MelonPreferences.cfg`의
`[sxtg2]`에서 `LogLevel = 2`로 바꾸세요(설명은 `03-development/DEBUGGING_GUIDE.md`).

## 1) 커스텀 곡이 곡 목록에 안 보임

- 로그에서 `[TrackDataAnalyzer] 커스텀 트랙 N개 추가 완료`를 찾으세요. 곡 선택 화면에 들어갈 때마다 찍힙니다.
- N이 0이거나 기대보다 적으면:
  - BMS가 `hwa\{앨범}\` 바로 아래에 있는지 확인(2단계 이상 아래는 안 찾음)
  - 확장자가 `.bms`/`.bme`/`.bml`인지 확인
  - 한 폴더에 BMS가 여러 개면 하나만 등록됨 — 폴더를 나누세요
- `[TrackDataAnalyzer] 앨범 추가 실패 (...)` 경고가 있으면 그 폴더의 곡 정보 txt를 확인하세요.
- 곡 제목이 앨범 폴더 이름으로 나오면 곡 정보 txt가 없거나 못 읽은 것입니다. 파일이 UTF-8인지, 키가 `제목:`/`title:`인지 확인하세요.
  로그에 `[TrackInfoParser] …UTF-8이 아닙니다` 또는 `…하나도 읽지 못했습니다` 경고가 남습니다(자세한 줄은 `LogLevel = 2`).
- `hwa` 폴더는 모드가 자동으로 만듭니다. 폴더 위치는 `sxtg2.dll`이 들어간 `Mods` 폴더와 같은 게임 설치 폴더입니다.

## 2) 커스텀 차트가 아니라 원래 곡 패턴이 나옴

- `[ManagerPlayHook] 차트를 읽지 못해 원본 패턴을 유지합니다: ...` → BMS에서 노트를 하나도 읽지 못했습니다.
  - 채널/값 규칙이 sxtg2 방식인지 확인(`02-systems/BMS_FORMAT.md`). 일반 키음 BMS는 값이 `01`~`05`가 아니라 무시됩니다.
  - 데이터 줄 형식은 `#MMMCC:데이터`(마디 숫자 + 채널 두 글자)입니다. 공백이나 문자가 섞인 줄은 헤더로 보고 무시합니다.
- `[CustomChartInjector] 노트 주입 실패 - 도너 패턴을 그대로 사용합니다` 오류 → 예외 내용을 확인하세요. 이때 게임 데이터는 바뀌지 않고 원래 곡
  패턴으로 진행됩니다.
- 정상이면 `[CustomChartInjector] N개 주입, totalNotes=..., totalNoteWithTicks=..., BPM=..., trackStartTiming=0`이 찍힙니다.
  `totalNotes`가 BMS의 노트 수와 비슷한지 확인하세요.

## 3) 플레이 도중 판정이 멈춤 / 점수가 안 오름 / 노트가 안 사라짐

- 끝(`03`/`05`)이 없는 홀드/오픈 노트는 이제 판정을 멈추지 않습니다. 로그에 경고가 남습니다:
  - `[CustomChartInjector] 끝(03)이 없는 홀드 N개를 일반 노트로 바꿨습니다` → 홀드 시작(`02`) 뒤에 같은 레인의 끝(`03`)을 넣으세요.
  - `[CustomChartInjector] 끝(05)이 없는 오픈 노트 N개에 기본 길이 1초를 줬습니다` → `04` 뒤에 `05`를 넣으세요.
  - `시작이 없는 끝 노트(03/05) N개는 무시했습니다` → 짝 없는 `03`/`05`를 지우세요. 경고에 레인과 시각 예시가 나옵니다.
- 그래도 `NullReferenceException`이 `RG_PS_Judgement` 근처에서 반복되면 로그 전체를 확인하세요(`LogLevel = 2`).

## 4) 이상한 위치에 노트가 생김 (곡 시작 직후)

- BMS 헤더 줄(`#TITLE Remix 2011:0101` 등)은 `#`와 `:` 사이 형식이 틀려서 이제 데이터로 읽히지 않습니다. 그래도 가짜 노트가 있으면
  `#00111:…`처럼 데이터 줄 형식을 가진 줄이 실제로 섞여 있는지 확인하세요.
- `#BPM`이 무한대/10만 초과 같은 값이면 무시하고 다음 `#BPM`(없으면 150)을 씁니다. 곡의 BPM이 맞는지 확인하세요.
- 채널 `02`(마디 길이)나 BPM 변화 채널을 쓴 BMS는 지원하지 않아 타이밍이 어긋납니다(`CURRENT_STATUS.md`의 남은 문제).

## 5) BGM이 교체되지 않음 / 이상한 소리가 BGM으로 나옴

- `[BGMPlayerHook] 앨범 폴더에서 BGM 파일 발견: ...` → 어떤 파일이 골라졌는지 확인
  - `music.*`가 없으면 폴더에서 **가장 큰** `.ogg`/`.mp3`/`.wav`를 고르고 경고를 남깁니다. 엉뚱한 파일이 골라졌다면 곡 음원 이름을 `music.ogg`로 바꾸세요.
- `[BGMPlayerHook] BGM 대상 또는 파일을 찾을 수 없습니다.` → 오디오 파일이 없음
- `[BGMPlayerHook] BGM 로드 실패: ...` → `UnityWebRequest` 오류. 파일이 손상됐을 수 있습니다(폴더 이름의 `#`/`%`/`?`는 이스케이프해서 읽습니다).
- 정상이면 `[BGMPlayerHook] BGM 교체 완료: music.ogg`
- 교체에 실패하면 도너 곡(곡 목록 첫 곡)의 BGM이 나오고, 곡 종료 시점도 그 BGM 길이로 정해집니다.

## 6) BGA가 교체되지 않음

- 게임 설정에서 BGA가 켜져 있는지 확인(꺼져 있으면 시도하지 않음)
- `.mp4`만 찾습니다(여러 개면 이름순 첫 파일). `[BGAPlayerHook] 앨범 폴더에서 BGA 파일 발견`/`BGA 교체 완료` 로그를 확인하세요.
- `[BGAPlayerHook] VideoPlayer.Prepare 실패` → 코덱 문제일 수 있음. H.264 mp4로 다시 인코딩해 보세요.

## 7) BGA와 BGM 싱크가 계속 어긋남

- `BGABGMSyncHook`은 0.1초마다 비교해서
  - 0.05초(보정 중이면 0.01초) 넘게 차이 나면 **소프트 싱크**(재생 속도 ±2~5%)
  - 0.5초 넘게 차이 나면 **하드 싱크**(BGA 시간을 BGM 위치로 이동)
- 영상이 `canSetPlaybackSpeed`를 지원하지 않으면 소프트 싱크가 안 되고 하드 싱크만 동작합니다.
- BGA 영상이 곡보다 짧으면 영상이 끝난 뒤에는 동기화 훅이 건드리지 않습니다(마지막 프레임에서 멈춘 채로 남음).
- 상세 로그는 `LogLevel = 2`일 때만 나옵니다(`[BGABGMSyncHook] ...`).
- BGM 시작 시각은 모드가 0초로 고정합니다(`trackStartTiming=0`). BGM이 차트보다 늦거나 빠르면 BMS 쪽의 오프셋을 확인하세요.

## 8) 자켓이 안 나옴

- `[TrackDataMediaHook] 커스텀 자켓을 찾지 못해 기본 자켓을 사용합니다: ...` (곡마다 한 번만 남음)
  - 앨범 폴더에 `thumb.png`(또는 `thumbnail.png`, `jacket.png`, `cover.png`, `image.png`)를 넣으세요.
- `[ThumbnailLoader] 자켓 로드: thumb.png (WxH)`가 찍히면 정상입니다.
- 자켓은 원본 해상도 그대로 메모리에 올립니다. 앨범이 많은데 메모리가 부담되면 자켓을 1024px 정도로 줄여서 넣으세요.

## 9) config.txt를 고쳤는데 반영이 안 됨

- v1.1.0부터 **플레이 씬에 들어갈 때** 다시 읽습니다. 곡 선택 화면에서 저장하고 다음 곡을 시작하면 됩니다.
  (한 판 도중에는 바뀌지 않음)
- 로그에서 `[SaveCustomKey] 설정 재로드 #n (...) - N개 항목이 이번 플레이부터 적용됩니다`와 바뀐 항목을 확인하세요.
  `변경 없음`은 `LogLevel = 2`일 때만 찍힙니다.
- 잘못된 설정은 경고가 납니다(기본값 유지):
  - `[SaveCustomKey] 알 수 없는 설정 키를 무시합니다: ...` → 키 이름 오타
  - `[SaveCustomKey] ... 켜기/끄기로 읽지 못했습니다` → 허용 단어는 `INSTALL_AND_LAYOUT.md` 6절
  - `[SaveCustomKey] ... 값을 숫자로 읽지 못했습니다` / `범위여야 합니다` → 숫자 형식/범위 오류
  - `[SaveCustomKey] 키=값 형식이 아닌 줄을 무시합니다` → `키=값` 형태로 쓰세요
- 값 뒤의 줄 끝 주석(`AutoPlay=1 # 메모`)은 인식합니다(주석 기호 앞에 공백).
- `[SaveCustomKey] 설정 파일 읽기 실패 - 기존 값을 유지합니다` → 편집기가 파일을 잠그고 있음. 저장 후 다시 시작하세요.
- 모드는 플레이 중 재로드 때 `config.txt`를 다시 쓰지 않습니다(없는 항목 자동 추가는 게임 시작 때만).

## 10) 기록이 저장되지 않음 / 업적이 안 열림

- 커스텀 곡, `AutoPlay`, `AllPerfect`, `MaxScore` 변경 플레이는 항상 기록 저장/서버 전송을 막고, Steam 업적과 플레이 횟수에도 반영하지 않습니다
  (의도된 동작, `INSTALL_AND_LAYOUT.md`의 "BlockSave와 기록 보호").
- 원본 곡을 평범하게 플레이했는데 기록이 안 남는다면 `config.txt`의 `BlockSave`가 `1`인지 확인하세요(기본값). `0`으로 바꾸면 다음 플레이부터 저장됩니다.
  (예전에는 MelonPreferences의 `BlockSaveBestRanking`이 `config.txt`를 덮어써서 `BlockSave=0`이 안 먹었지만 지금은 읽지 않습니다.)
- 차단될 때마다 `[차단] 하이스코어 및 랭킹 저장 차단(사유): LyrebirdServer.PostUserScore`(또는 `UserAccountModule.SavePlayData`) 로그가 남습니다.
  `SavePlayData`는 새 최고 기록/풀콤보/랭크가 있을 때만 불리므로 그 줄은 매번 나오지 않습니다.
- 업적/플레이 횟수를 되돌릴 때는 `[ResultTaint] 이번 결과는 업적/플레이 횟수에 반영하지 않습니다` 로그가 남습니다.
- 결과 화면의 베스트 점수 표시는 차단과 상관없이 원본처럼 갱신됩니다(저장만 막음).

## 11) 커스텀 노트 스킨이 적용되지 않음 / 너무 크거나 작음

- 파일 이름은 `Blue.png`/`Red.png`/`White.png`/`Gate.png`, 홀드 끝은 `Blue_tail.png`, 몸통은 `Blue_hold.png` 형식입니다(`INSTALL_AND_LAYOUT.md` 5절).
- `[CustomNoteSpriteLoader] 총 N개의 커스텀 노트 스프라이트 로드 완료` → 로드된 파일 수(각 파일의 가로×세로도 로그에 나옴)
- `LogLevel = 2`면 노트마다 `[NoteSpriteHook] 노트 생성: name=..., 추출된 타입=...`이 찍혀 실제 노트 이름을 확인할 수 있습니다.
- 스킨은 PNG 원본 크기로 표시되고, 게임의 노트 크기 옵션(`noteSize`)이 다시 곱해집니다. 크기가 이상하면 PNG 크기를 조정하세요.
- PNG는 게임 시작 시 한 번만 읽으므로, 추가/수정 후에는 게임을 다시 켜야 합니다.

## 12) 판정바에 틱이 안 나옴

- 판정바 데이터는 게임의 **플레이 위젯**을 통해 들어옵니다. 게임 설정에서 위젯을 하나도 장착하지 않으면 틱과 오차
  텍스트가 나오지 않습니다(남은 문제). 위젯을 아무거나 하나 장착하세요.
- `EnableJudgmentBar`/`EnableKeyViewer`가 `1`인지 확인하세요. 오버레이는 실제 플레이 씬(`Play`)에서만 그려지고 로딩 화면(`PlayLoading`)에는 나오지 않습니다.

## 13) Score/클리어 사운드가 이상함

- 커스텀 차트의 점수/클리어 효과음은 주입된 노트 수를 `SXGTData.totalNotes`/`totalNoteWithTicks`에 반영하는 방식으로
  동작합니다. `[CustomChartInjector] ... totalNotes=..., totalNoteWithTicks=...` 값이 실제 BMS 노트 수와 비슷한지 확인하세요.
- `MaxScore`를 바꿨다면 `[JudgeScoreMax] Update: 만점 상수 1곳 교체 완료`, `CalculateJudgeScore: ... 1곳` 로그를 확인하세요.
  `만점 상수(1000000)를 찾지 못했습니다` 경고는 게임 업데이트로 코드가 바뀌었다는 뜻입니다.
- `MaxScore`를 700000 이하로 낮추면 풀콤보가 아닐 때 `Clear_Normal`이 나오지 않습니다(게임의 고정 기준값).
- **(2026-07-18 수정됨) 곡 중간에 클리어 사운드가 나오던 문제**: `totalNotes`/`totalNoteWithTicks`가 도너 곡 기준으로 남아
  있던 것이 원인이었고, `CustomChartInjector`가 주입 직후 다시 계산하도록 고쳤습니다. 자세한 내용은 `02-systems/SCORE_SYSTEM.md`.

## 14) 로그가 너무 많음

- 곡 선택 확인창과 결과 화면의 진단 로그(`[MusicSelectDiagnostics] …`, `[ManagerResultHook] …`, `[OperatorCharacterHook] …`)는 이제 `LogLevel = 2`에서만
  나옵니다(시이(Shii) 조사용). 기본 `LogLevel = 1`에서는 나오지 않습니다.
- 곡 정보 파일 로그(`[TrackInfoParser] 곡 정보 파일 발견/제목/아티스트/난이도`)도 `LogLevel = 2`에서만 나옵니다.

## 15) GATE 노트를 칠 수 없음 / 오픈 노트 이후 게이트가 이상함

- 게이트는 닫힌 채 시작하고, 닫혀 있으면 게임이 GATE 키 입력을 무시합니다. `18` 채널 노트 앞에 오픈 노트(`04`~`05`)가 없으면
  그 노트는 칠 수 없는 미스가 됩니다. 앞쪽에 오픈 노트를 넣어 게이트를 먼저 여세요.
- 오픈 노트 한 쌍은 게이트를 **한 번 토글**합니다(열려 있으면 닫음). 다시 닫으려면 오픈 노트를 한 번 더 넣어야 하고, 두 노트 사이 길이는
  열리는 애니메이션 시간일 뿐 "열려 있는 시간"이 아닙니다(`02-systems/BMS_FORMAT.md`의 "게이트와 오픈 노트" 절).
- 오픈 노트에 끝(`05`)이 없으면 모드가 기본 길이 1초를 줍니다(경고 로그). 의도한 애니메이션 길이가 있으면 `04` 뒤에 `05`를 두세요.
- 오토플레이는 오픈 노트를 치지 않지만 게이트 토글은 시간이 되면 알아서 일어납니다.

## 16) 랭킹 창이 안 열리거나 오류가 남 (커스텀 곡)

- 커스텀 곡의 랭킹은 서버에 없으므로 빈 목록으로 열립니다(서버 요청을 보내지 않음). 예전에는 곡을 못 찾아 `NullReferenceException`이 났습니다.
