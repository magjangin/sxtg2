# 📄 BMS 파일 포맷 (sxtg2 방식)

기준일: 2026-09-28 (v1.1.0, `Loaders/BmsParser.cs` 기준)

sxtg2는 일반 BMS(키음 번호를 채널에 배치)와 다른 **전용 규칙**을 씁니다.

- **채널 번호 → 게임 레인**을 정하고,
- **값(오브젝트 번호) → 노트 종류**를 정합니다. 값은 키음 번호가 아니라 `01`=일반, `02`=홀드 시작 같은 약속된 코드입니다.

---

## 파일 구조

```bms
#BPM 150

#00116:01000100
#00111:02000000
#00211:00000300
#00104:04000000
#00204:00050000
```

## 헤더

| 헤더 | 사용 여부 | 설명 |
| --- | --- | --- |
| `#BPM <숫자>` | ✅ | 기본 BPM. 파일 어디에 있든 **처음 나오는 올바른 값(0 초과 10만 이하)** 하나만 씁니다. 없으면 `150`. `Infinity`처럼 범위를 벗어나거나 숫자가 아닌 값은 건너뛰고 다음 `#BPM`을 봅니다 |
| `#WAVxx` / `#WAVxxx` | ⚠️ 너비 판별에만 | 키 이름이 `WAV` + 영숫자 3자리(`WAV001`, `WAV00A`)인 줄이 하나라도 있으면 데이터 값을 **3글자 단위**로 읽습니다. 6글자라도 `#WAVCMD` 같은 명령 줄은 키음 번호가 아니라서 제외합니다(예전에는 길이만 봐서 이런 줄이 있으면 노트가 0개가 됐음) |
| `#BPMxx`, `#TITLE`, `#ARTIST`, `#PLAYLEVEL`, `#BMP` 등 | ❌ | 무시. 곡 제목/아티스트/난이도는 `trackinfo.txt`에서 읽습니다(`BMS_SELECTION.md`) |

## 데이터 라인

```text
#MMMCC:데이터
```

- `MMM`: 마디 번호(10진수). `#CC:데이터`처럼 생략하면 마디 0.
- `CC`: 채널. 콜론 바로 앞 **두 글자**를 채널로 봅니다. `#`와 `:` 사이(채널부)는 `숫자(마디) + 영숫자 두 글자` 형식이어야 하고, 공백이나 다른 문자가 섞인 줄(`#TITLE Remix 2011:0101`)은 헤더로 보고 무시합니다.
- 데이터: 값 2글자씩(또는 3글자씩) 이어 붙인 문자열. 값 개수로 마디를 균등 분할합니다.
- 같은 마디·채널 줄이 여러 개 있으면 전부 읽어 합칩니다(겹치는 위치면 노트가 두 개 생김).

## 채널 → 레인

| BMS 채널 | 게임 레인 (`LaneIndex`) | 노트 색 (`NoteColor`) | 게임이 쓰는 노트 프리팹 |
| --- | --- | --- | --- |
| `16` | 0 (`LL`) | `BLUE` | Blue |
| `11` | 1 (`L`) | `BLUE` | White |
| `12` | 2 (`R`) | `BLUE` | White |
| `13` | 3 (`RR`) | `BLUE` | Blue |
| `14` | 4 (`LT`) | `RED` | Red |
| `15` | 5 (`RT`) | `RED` | Red |
| `18` | 6 (`GATE`) | `BLUE` | Gate |
| `04`, `05` | 값이 `04`/`05`일 때만 → 9 (`OPEN`) | `OPEN` | Blue |

- 프리팹은 게임의 `NoteGenerator.Generate`가 `targetLane`과 색으로 고릅니다(디컴파일 기준).
- 그 밖의 채널(`01` BGM, `02` 마디 길이, `03`/`08` BPM 변화, `09` STOP, `17`, `19`, 2P `2x`, 롱노트 `5x`/`6x` 등)은 전부 무시합니다.
- 일반 BMS에서 `04`는 BGA 채널이지만, sxtg2에서는 오픈 노트용으로 씁니다.

### 게이트(GATE)와 오픈 노트의 실제 동작 (디컴파일 원본 기준, 2026-10-05)

- **게이트는 닫힌 채 시작합니다.** 게이트가 닫혀 있으면 게임이 GATE 키 입력을 아예 무시합니다(`ManagerPlay.OnLaneKeyDown/Up`,
  `RG_Gear.IsGateOpened` 기본값 `false`). 그래서 `18` 채널(GATE) 노트는 **앞에 오픈 노트가 있어 게이트를 열어 둬야** 칠 수 있습니다.
  오픈 노트 없이 `18` 채널만 쓰면 그 노트는 전부 칠 수 없는 미스가 됩니다.
- **오픈 노트 한 쌍(`04`~`05`)은 게이트를 한 번 "토글"합니다.** 시작 시각이 되면 `CheckOpenState`가 닫혀 있으면 열고 열려 있으면
  닫은 뒤 곧바로 다음 오픈 노트로 넘어갑니다. 끝(`05`) 시각은 "그때까지 열려 있다"는 뜻이 **아니라** 열리고 닫히는
  **애니메이션 길이**(`SwitchGateOpenState(duration)`)로만 쓰입니다. 게이트를 다시 닫으려면 오픈 노트를 한 번 더 넣어야 합니다.
- 끝(`05`)이 없으면 길이가 0이 되어 게임이 `animator.speed = 1f / 0f`(무한대)를 설정하므로, 모드가 **기본 길이 1초**를 주고 경고를 남깁니다. 의도한 애니메이션 길이가 있으면 모든 `04` 뒤에 `05`를 두세요.
- 오픈 노트(레인 9)는 점수 노트 수(`totalNotes`)에 포함되지 않고, 오토플레이(`AutoPlayJudge`)도 치지 않습니다. 게이트 토글은
  판정과 무관하게 시간만 되면 일어납니다.

## 노트 값

| 값 | 종류 (`BmsParser.NoteType`) | 게임 노트 |
| --- | --- | --- |
| `00` | 빈 칸 | — |
| `01` | `Normal` (일반) | `ShortNote` |
| `02` | `Long` (홀드 시작) | `HoldNote` |
| `03` | `HoldEnd` (홀드 끝) | 파싱 후 제거, 길이 계산에만 사용 |
| `04` | `Open` (오픈 시작) | `HoldNote`, 레인 9, 색 `OPEN` |
| `05` | `Close` (오픈 끝) | 파싱 후 제거, 길이 계산에만 사용 |
| 그 외 | — | **무시** (키음 번호 등) |

- `04`/`05` 값은 채널과 관계없이(레인 채널 `11`~`18`에 써도) 레인 9로 들어갑니다.
- 3글자 모드에서는 첫 글자가 `0`일 때만 떼고 비교합니다: `001`→`01`(일반), `002`→`02`. `101` 같은 값은 무시됩니다.

## 홀드 짝 맞추기

레인별로 시간순 정렬한 뒤, 시작(`02`/`04`) 다음에 오는 첫 끝(`03`/`05`)과 짝을 짓습니다.
길이 = 끝 시간 − 시작 시간. 짝 사이의 일반 노트는 영향을 주지 않습니다.

- 끝 없이 다음 시작이 나오거나 파일이 끝나면 → `MissingEndNotes` 통계에 기록
- 시작 없이 끝만 있으면 → `OrphanEndNotes` 통계에 기록하고 버림

짝이 없는 노트는 주입 단계(`CustomChartInjector`)에서 이렇게 처리하고 경고 로그를 남깁니다(2026-10-05부터):

| 상황 | 처리 |
| --- | --- |
| 끝(`03`) 없는 홀드 시작(`02`) | **일반 노트**(`ShortNote`)로 바꿈. `HoldNote`로 넣으면 `tickTime`이 null이라 게임 `CheckHoldTick`이 `NullReferenceException`을 내고 판정 루프가 멈추기 때문 |
| 끝(`05`) 없는 오픈 노트(`04`) | 기본 길이 **1초**의 `HoldNote`로 넣음(오픈 노트는 판정 커서가 `HoldNote`여야 넘어가고, 길이 0이면 게이트 애니메이션 속도가 무한대가 됨) |
| 시작 없는 끝(`03`/`05`) | 버림(`OrphanEndNotes`) |

경고 로그에는 레인과 시각 예시가 최대 5개 나옵니다. 의도한 결과가 아니면 채보에서 `02`/`04` 뒤에 짝을 맞추세요.
## 시간 계산

```text
tick = 마디 + (칸 번호 / 그 줄의 칸 수)
time(초) = tick × 240 / BPM
```

`240 = 4박 × 60초`로, 4/4박자 한 마디의 길이가 `240 / BPM`초라는 뜻입니다.

예시 (`#BPM 150`, `#00116:01010101` → 칸 4개):

| 칸 | tick | time |
| --- | --- | --- |
| 0 | 1 + 0/4 = 1.00 | 1.00 × 240 / 150 = 1.600초 |
| 1 | 1 + 1/4 = 1.25 | 1.25 × 240 / 150 = 2.000초 |
| 2 | 1 + 2/4 = 1.50 | 2.400초 |
| 3 | 1 + 3/4 = 1.75 | 2.800초 |

### 지원하지 않는 것

- **BPM 변화**(`03`/`08` 채널, `#BPMxx`): 곡 전체가 `#BPM` 하나로 계산됩니다.
- **마디 길이 변경**(`02` 채널): 무시되므로, 쓰면 그 뒤 모든 노트 타이밍이 어긋납니다.
  예: `#00102:0.5`가 있어도 마디 2의 노트는 `2 × 240 / 150 = 3.2초`로 계산됩니다(원래는 2.4초여야 함).
- **STOP**(`09`), `#RANDOM`/`#IF` 제어문, 키음·BGA 재생.

## 게임 쪽 BPM 사용

`CustomChartInjector`는 `SXGTData.bpm`을 `[BPM]` 하나로 덮어씁니다. 게임은 이 값으로 홀드 틱 간격
(16분음표 = `60 / BPM / 4`초)과 판정 모듈의 틱 간격을 정하므로, `#BPM`은 곡의 실제 BPM과 맞춰 두는 것이 좋습니다.
홀드 틱 계산식은 `NOTE_SYSTEM.md` 참고.

## 파싱 관련 참고

- 헤더 줄(`#TITLE …`, `#ARTIST …` 등)은 채널부 형식 검사에서 걸러지므로 값에 콜론이 있어도 가짜 노트가 생기지 않습니다(2026-10-05부터).
  그래도 제목/아티스트/난이도는 `trackinfo.txt`에 쓰세요(BMS 헤더의 값은 읽지 않습니다).
- 파일은 UTF-8(BOM 자동 인식)로 읽습니다. 데이터 줄은 ASCII라 인코딩 영향이 없습니다.
## 파일 예시

### 일반 + 홀드

```bms
#BPM 140
#00111:02000000
#00111:00000300
#00112:01010101
```

마디 1의 레인 1(`L`)에 홀드(1.714초 ~ 2.571초 — 끝 `03`은 4칸 중 2번 칸, tick 1.5), 레인 2(`R`)에 일반 노트 4개.

### 오픈/클로즈

```bms
#BPM 160
#00104:04000000
#00204:05000000
#00111:01010101
```

마디 1 시작부터 마디 2 시작까지 오픈 노트(레인 9) 하나. 게임에서는 마디 1 시작에 게이트가 **열리고**(애니메이션 길이 = 한
마디), 닫히지는 않습니다. 이 뒤의 `18` 채널 노트는 칠 수 있고, 닫으려면 오픈 노트를 하나 더 넣어야 합니다.
